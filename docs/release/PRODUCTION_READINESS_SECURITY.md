## Remaining acceptance

PR-SEC-003 tracks the incomplete exhaustive role/object/action matrix. Required closure includes ordinary roles, changed/revoked grants, active/verified status, both transfer warehouses, cross-branch customers/projects/tenders, invoice and private-document/export routes, financial/cost masking, approval independence and failed mutations leaving no effects. Use existing records in each isolated fixture: 404 for an invented ID is not proof of IDOR protection.

Fresh browser and backend receipts must be read with their recorded fixture/harness failures. The audit did not expose credentials, disable security middleware, authorize accounts in the operational database, test a public host, or claim all routes secure.
