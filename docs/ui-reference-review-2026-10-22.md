طلب المالك مراجعة آخر نحو 40 شاشة ومقارنتها بالمراجع المرسلة. تم ترتيب آخر 40 **لقطة متاحة** بحسب تاريخ تعديل الملف في docs وartifacts. هذه ليست 40 شاشة مستقلة: تتضمن إعادة تصوير لنفس النموذج وحالات الأخطاء والجوال وRTL/LTR وصفحة تسجيل الدخول.

- المقارنة بالمراجع المرسلة في المحادثة للمبيعات والمخزون والمشتريات والمشروعات.
- لا توجد لقطات حديثة للمشروعات في تلك الأربعين؛ مراجعتها الحالية من القوالب، وليست قبولًا بصريًا.

## الفروق وما تغير

| الفرق | التحسين المنفذ |
|---|---|
| فراغات كبيرة وحواف مستديرة أكثر من المراجع | تقليل حشو سطح العمل واللوحات وحوافها، وإبقاء عناصر التفاعل واضحة |
| عنوان ضخم وشريط جانبي زخرفي | عنوان أصغر دون الشريط، ووصف ثانوي واضح |
| ألوان أزرار رئيسية غير موحدة | أزرق موحد مع حالة hover وتركيز لوحة المفاتيح |
| تفاوت كثافة الجداول | عناوين زرقاء فاتحة، حدود دقيقة، تباعد صفوف موحد وأرقام ثابتة العرض |
| تفاوت بطاقات المؤشرات | إعادة استخدام erp.stat-card في لوحة المشتريات وقائمة/لوحة المشروعات، وتمييز الحالات بأيقونات وألوان دلالية |
| نسب تقدم مجردة | شريط تقدم مع النسبة في قائمة المشروعات، وتسميات وصول للأشرطة |
| حالات إنجليزية في تقرير المشروعات | عرض التسميات العربية |
| تباعد وحقول مختلفة | ضبط الخط والحواف والحدود والتركيز في Flux داخل سطح ERP |

التغيير المشترك يصل إلى مستخدمي panel/stat-card والعنوان والجداول داخل shell، ومنها المبيعات والمنتجات والأطراف والتنظيم، وليس إلى قوالب المشروعات فقط. لم تتغير الاستعلامات أو الصلاحيات أو إجراءات الأعمال أو الأرصدة.

## حدود التحقق

- بناء Vite نجح بعد التعديلات الأولى. تظهر تحذيرات مسارات الخطوط وقت البناء، رغم وجود ملفات الخطوط في public/fonts. لم يتم إثبات تحميلها في المتصفح.
- التحكم بالمتصفح رفض الاتصال برسالة: `Local browser use is disabled in Work settings`.
- لذلك لم تُلتقط صور بعد التعديل ولم تُثبت المطابقة بنفس viewport أو سلامة كل شاشة على الجوال.
- لم تُكتب أو تُشغل اختبارات آلية، حسب قرار المالك.
- الحالة: **تحسينات مشتركة منفذة، المطابقة البصرية PARTIAL وليست VERIFIED**.

## المتبقي

معاينة الصفحات الفعلية بعد إتاحة التحكم بالمتصفح؛ مراجعة التفاف العناوين والحقول والجداول والقوائم في RTL/LTR والجوال؛ استكمال تركيب كل لوحة بيانات وفق بياناتها الحقيقية. لم تُضف رسوم أو أرقام أو معاملات وهمية لإكمال تركيب المراجع.
